FAQ

How long does it take? +

Resume Refresh is delivered within 48 hours. Career Glow-Up ships in 24–48 hours since it's priority. Add the rush option to either package for a guaranteed 24-hour turnaround.

What if I don't like the draft? +

Each package includes revision rounds — send specific notes and I'll adjust the draft until it's right. Revisions are included in the price, not billed extra.

Do you write cover letters too? +

A custom cover letter template is included with Career Glow-Up. It's not included with Resume Refresh, but can be added on request.

Is this actually reviewed by a person? +

Yes. Every draft starts from an AI-assisted first pass, then gets personally reviewed and edited before it's sent to you — that review is what catches errors and makes it sound like you, not a template.

Can I get a refund? +

If work hasn't started yet, you can request a full refund. Once a draft has been delivered, refunds are handled case by case — reach out and we'll sort it out.
